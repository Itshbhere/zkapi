The browser SDK builds proofs and owns wallet recovery. Its package exports and
integration contract are documented in `sdk/README.md` in the repository.

```text
Browser SDK -> WASM prover -> server -> usage settlement and signed next state
     |                         |
     v                         v
  indexer                 SQLite transcripts
     |
     v
Native ETH vault <-------- challenge service
```

`protocol/rust/crates/zkapi-types/src/wire.rs` defines the protocol's JSON
messages. Runtime handlers in `crates/zkapi-serverd/src/routes.rs` and
`crates/zkapi-indexerd/src/http.rs` define the supported routes.
