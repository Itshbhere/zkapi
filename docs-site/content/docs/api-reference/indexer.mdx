title: indexer
description: Contract-event mirror and depth-32 Merkle paths

The indexer applies native vault events to a local Merkle tree. The browser
uses it for proving and deposits; the server uses it to track the active root.

| Method and path | Result |
| --- | --- |
| `GET /health` | Process health |
| `GET /v1/tree/root` | Current root |
| `GET /v1/tree/next-note-id` | Next unused note slot |
| `GET /v1/tree/snapshot` | Tree snapshot for client synchronization |
| `GET /v1/tree/notes/{note_id}/path` | Occupied leaf and 32 siblings |
| `GET /v1/tree/notes/{note_id}/zero-path` | Empty-leaf path for insertion or restoration |

The root, leaf, and siblings use canonical BN254 field encodings. The indexer
consumes deposit, close, escape, challenge, finalization, and expiry events
from Ethereum JSON-RPC. It persists replay progress and checkpoints to support
restart and chain synchronization.

An indexer cannot forge membership: clients and contracts recompute roots from
the supplied paths. Incorrect or stale paths can cause proving or transaction
failure. The deployment pins the vault and network independently of indexer
responses.

## Leaf binding and private path lookup

The tree uses Poseidon over the BN254 scalar field with 32 sibling levels.
Each occupied leaf binds the note ID, secret-derived registration, deposit,
and expiry. The note-bound request and withdrawal circuits use this exact
leaf in both membership verification and the signed balance commitment.
The indexer's `/v1` URLs are independent of the proof protocol's v2 version.

`GET /v1/tree/snapshot` returns
`{ root: Felt252, next_note_id: u32, leaves: Felt252[] }`. Clients can rebuild
the tree and derive paths locally without revealing a particular note ID in a
request URL. Tree endpoints return `503` while initial chain replay is
incomplete.

Use current-root sibling paths when submitting a deposit, withdrawal, or
challenge restoration. A challenge separately supplies the original archived
request proof with its historical root; do not rewrite its public inputs to
the indexer's latest root.
